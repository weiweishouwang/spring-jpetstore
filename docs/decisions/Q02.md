# Q02：允许缺货加购，禁止缺货成交

## 决策

缺货商品允许加入购物车，但提交订单时各可售项必须库存充足；本期不支持缺货预订和超卖。

## 实现及验收边界

服务端原子校验并扣减正整数数量；任一项不足则整单回滚，库存不得为负；购物车有货提示仅作参考。
