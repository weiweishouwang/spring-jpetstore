# Q03：确认快照15分钟，变化重新确认

| 属性 | 内容 |
| --- | --- |
| 状态 | 已确认 |
| 确认来源 | 用户在本次会话对 T003 / Q03 的明确答复 |
| 适用范围 | 本期 JPetStore 现代化改造 |
| 关联 | ORD-06～07、D11、AT-R06 |

## 决策

确认页保存价格、购物车版本和交易内容快照，有效期15分钟；最终提交时价格或内容变化须要求用户重新确认。

## 实现及验收边界

服务端生成快照及到期时间；提交时当前时间达到或超过到期时间即失效。快照不预占库存，不承诺15分钟锁价。禁止静默替换价格或成交内容。

在对应实现任务先写目标失败测试，再实现并验证。本文确认的是业务规则，不代表应用已经实现或测试通过；与此无关的 Q 决策仍待确认。
