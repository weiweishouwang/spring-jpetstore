# Q08：按账号持久化并跨设备恢复购物车

| 属性 | 内容 |
| --- | --- |
| 状态 | 已确认 |
| 确认来源 | 用户本次会话明确答复 |
| 关联 | CRT-01、CRT-11、Q08；plan ADR-03 |

## 决策

登录账户的未成交购物车持久化保存，支持服务重启、会话过期后重新登录及跨设备恢复；主动退出不删除账户购物车。

## 边界及验收

这是用户明确批准的范围扩展，取代原先“仅会话隔离、不跨设备”的限制。读取/修改必须以当前登录用户授权，不能因知道cartId恢复他人内容；登录时合并游客购物车，同SKU数量相加；超限提示处理且保留双方内容，不静默截断。账户购物车保留至成交或手动移除；游客会话30分钟无活动失效，不承诺游客跨重启恢复。

本项记录用户决定，不代表应用已实现；先更新相关需求/任务，再测试先行实施。
