# Q13：账户归一化与密码政策

| 属性 | 内容 |
| --- | --- |
| 状态 | 已确认 |
| 确认来源 | 用户本次会话对T013的明确答复 |
| 适用范围 | 本期学习演示改造 |

## 决策

用户名trim后1～25字符、大小写敏感；其他必填文本拒绝纯空白；邮箱不要求唯一。密码8～64字符且UTF-8不超过72字节，不trim密码，超出拒绝不截断；改密后所有会话失效并重新登录。

## 验收与边界

密码hash字段独立varchar(255)，两次密码一致；资料编辑两次新密码均空仍表示不改密。停用状态和改密会话失效须在服务端执行，不能只靠前端退出。

确认规则不代表实现完成，后续依照tasks测试先行。
