# Q04：成交后消费本次购物车

| 属性 | 内容 |
| --- | --- |
| 状态 | 已确认 |

| 适用范围 | 本期 JPetStore 现代化改造 |

## 决策

成功后清理本次成交购物车；确认后其他标签页若修改购物车，先要求重新确认；提交失败保留内容。

## 实现及验收边界

消费购物车、消费确认快照、订单/明细/状态及库存扣减必须在同一个本地数据库事务内完成；不得在提交后依靠Session清理充当业务消费。
