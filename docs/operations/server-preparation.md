## 2. 准备清单

| 项目 | 准备内容 | 验证方式 | 结果 |
| --- | --- | --- | --- |
| 容器运行时 | Docker Engine + Compose v2，版本与开发环境一致 | `docker version`、`docker compose version` | 待执行 |
| 应用目录 | 独立目录存放 `infra/` 与发布清单，属主非 root，权限 0750 | `stat` 检查 | 待执行 |
| 运行用户 | 专用非 root 用户（uid 10001），只拥有应用目录读权限 | `id 10001`、以该用户启动一次 | 待执行 |
| 持久卷与磁盘 | 数据库卷与应用日志目录；可用空间 ≥ 数据量 × 3 | `df -h` | 待执行 |
| 网络与 runner | 部署 runner 能 SSH 到目标；备份 runner 能连数据库；应用只监听回环 | `nc -z`、从 runner 访问一次 | 待执行 |
| DNS 与 TLS | 域名解析到代理；证书链完整；续期方式明确 | `openssl s_client`、续期任务检查 | 待执行 |
| secret 注入 | 凭据通过受限文件或 secret 管理注入，容器内环境变量只保留引用名 | `docker inspect` 检查镜像无凭据、运行时无明文 | 待执行 |
| 受限数据库账号 | 应用账号（业务读写）与迁移账号（仅迁移）分离 | 用迁移账号执行一次 `flyway validate` | 待执行 |
| 时钟与时区 | 主机时钟同步，UTC 生效 | `timedatectl` | 待执行 |
| 日志与轮转 | 容器日志 json-file 轮转已配置 | `docker compose config` 复核 | 待执行 |
